# Christopher Aniedi — Portfolio

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · shadcn/ui · Motion

Built from the Figma file **My Portfolio (Copy)** → page *Portfolio* → frame `1:205`.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

Open http://localhost:3000.

## Where things live

| What | Where |
| --- | --- |
| All copy, links, projects, testimonials, gallery | `lib/site.ts` |
| Colours, fonts, radii (design tokens) | `app/globals.css` |
| Landing page sections | `components/sections/*` |
| shadcn primitives | `components/ui/*` |
| Images | `public/images/*` (WebP, optimised) |

Inner pages (`/about`, `/notes`, `/talks`) are placeholders until they're built from Figma.
